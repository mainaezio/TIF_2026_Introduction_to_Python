Per gli utenti Windows "Aprire un terminale" deve essere inteso come aprire un terminale in WSL.

  • Aprite un terminale
  • Date il comando cd per essere sicuri di essere nella vostra cartella home
  • Verificate con pwd l'indirizzo della cartella home
  • Scaricate il file http://www.to.infn.it/~maina/test_FileSystem/ nel modo seguente
    • Si apre una pagine che contiene un singolo link al file test_FileSystem.tar.gz
    • Cliccate con il tasto destro del mouse sul nome del file
    • Scegliete ''Salva con nome''. Il sistema vi propone una cartella in cui scaricare il file. Prendete nota di dove il file viene scaricato.
    • Andate nella cartella home (cd)
    • Create una nuova directory con il comando mkdir precorso
    • Spostate il file test_FileSystem.tar.gz dalla cartella in cui è stato scaricato alla cartella precorso (mv). Può essere utile usare indirizzi assoluti.
    • Nella directory precorso, date il comando tar -ztvf test_FileSystem.tar.gz
      Il sistema vi mostra i file contenuti nell'archivio test_FileSystem.tar.gz
    • Date il comando (in cosa differisce dal comando precedente?) tar -zxvf test_FileSystem.tar.gz
      I file contenuti nell'archivio test_FileSystem.tar.gz vengono estratti e salvati localmente
    • Verificate con ls -al quali file sia presenti nella cartella.
      La risposta attesa è: 
      total 100056
drwxr-xr-x   6 maina  staff       192 Sep 23 08:19 .
drwxr-xr-x  22 maina  staff       704 Sep 23 08:19 ..
drwxr-xr-x@ 45 maina  staff      1440 Aug  9  2023 Humour
drwxr-xr-x@ 42 maina  staff      1344 Aug 10  2023 bin
drwxr-xr-x@  7 maina  staff       224 Aug 10  2023 phantom
-rw-r--r--   1 maina  staff  51225147 Sep 22 15:16 test_FileSystem.tar.gz
Congratulazioni!

 Esercizi 2 
Questa seconda parte di esercizi richiede i file e le cartelle scaricate in precedenza.
Se è necessario (Per esempio sui Thin-client delle aule F e G su cui tutti i file creati dall'utente vengono eliminati alla fine della sessione.) scaricate nuovamente il materiale con i comandi descritti più sopra.

 

  • Aprite un terminale se necessario.
  • Spostatevi nella cartella in cui avete decompresso test_FileSystem.tar.gz se necessario
  • Date il comando ls -al Humour per vedere la lista dei file nella cartella Humour.
  • Verificate che in Humour sia presente la cartella ScienceJokes
  • Date il comando ls -al Humour/ScienceJokes per vedere la lista dei file nella cartella Humour/ScienceJokes.
  • bash ha la capacità di completare indirizzi incompleti:
    scrivete sulla linea di comando ls -al Humour/Sc e premete il tasto Tab
    bash completa l'indirizzo. Premete Invio per eseguire il comando
  • È possibile usare ls per verificare che un certo file sia presente:
    date il comando ls Humour/ScienceJokes/ScientificMethod.jpg
    date il comando ls Humour/ScienceJokes/Scientific.jpg. Cosa succede?
  • Provate il comando ls con le opzioni -lh, -lt, -ltr su Humour/ScienceJokes
  • È possibile usare ls per vedere solo un sottoinsieme dei file: date il comando ls Humour/Ca*
    Il simbolo *, detto wildcard, significa "qualunque sequenza di caratteri", quindi Ca* vuol dire qualunque file il cui nome inizi con Ca, *pdf qualunque file che finisca con pdf, F*oo*jpg qualunque file inizi con F, contenga oo e finisca con jpg
    date il comando ls Humour/*pdf
    date il comando ls Humour/F*oo*jpg
  • bash tiene memoria degli ultimi comandi che avete immesso. Per richiamare i comandi precedenti usate le frecce verso l'alto e verso il basso. Quando il comando che vi serve compare sulla linea di comando lo potete modificare spostandovi con la frecce verso destra e sinistra. Potete cancellare o inserire qualunque carattere. Premete Invio per eseguire il nuovo comando. Provate per credere.
  • Date il comando mkdir Humour/pluto per creare la cartella pluto all'interno di Humour
  • Dalla cartella in cui avete decompresso l'archivio date il comando cp Humour/Ca* Humour/pluto per copiare tutti i file in Humour il cui nome inizi con Ca nella cartella Humour/pluto. Verificate con ls che l'operazione sia andata a buon fine.
  • cancellate la cartella pluto e tutti i file che contiene
  • Tornate alla cartella in cui avete decompresso l'archivio
  • Date il comando find ./ -name micro
    Il comando cerca tutti i file e cartelle il cui nome è micro. La ricerca esamina la cartella in cui sto lavorando e in tutte le cartelle sottostanti (./ è la cartella in cui mi trovo)
  • Usate il comando find per cercare il file Makefile nella cartella bin/form
  • È possibile fornire a find l'indizzo assoluto della cartella da cui iniziare la ricerca:
    find /usr/bin -name curl
  • Anche con find è possibile usare delle wildcard. In questo caso il nome dei file da cercare va chiuso fra virgolette:
    find /usr/bin -name "cu*"
    find ./ -name "*bash*"
  • Date il comando man find ed esaminate il risultato. Si, è un po' complicato
  • Nel vostro browser preferito cercate linux find. Aprite le prime pagine della risposta. Il web è una grande risorsa per tutti i problemi di programmazione. Non sempre è immediato trovare esattamente quello che serve.
  • Il comando cerca una serie di caratteri all'interno dei file.
    Dalla cartella in cui avete decompresso l'archivio date il comando cat phantom/COMANDI_GCC.txt per mostrare sullo schermo il contenuto del file phantom/COMANDI_GCC.txt.
    Dalla cartella in cui avete decompresso l'archivio date il comando grep lhapdf phantom/COMANDI_GCC.txt.
    Il comando grep mostra tutte le linee nel file phantom/COMANDI_GCC.txt che contengono lhapdf
  • Usando man grep cercate l'effetto (e la sintassi) delle opzioni -A e -B su grep. Ripetete il comando grep lhapdf phantom/COMANDI_GCC.txt aggiungendo le opzioni -A e -B.
  • Provate i comandi head e tail su phantom/COMANDI_GCC.txt
  • I comandi di bash possono essere concatenati passando l'output del primo al secondo e così via. Per esempio nella vostra home date il comando ls -al. Il risultato può essere passato come input a grep per estrarre solo le cartelle per cui la riga contiene "drwx". Si usa il simbolo | (barra verticale): ls -al | grep drwx
  • Date il comando man grep e esaminate il risultato. Si, anche questo è un po' complicato
  • Nel vostro browser preferito cercate linux grep. Aprite le prime pagine della risposta.
  • Possiamo concatenare grep con se stesso per raffinare una ricerca. Date il comando grep lhapdf phantom/COMANDI_GCC.txt | grep home.
    Il comando mostra tutte le linee nel file phantom/COMANDI_GCC.txt che contengono lhapdf. Il risultato viene passato nuovamente a grep per selezionare le linee che contengono anche home.
